# Analog Clock & Bakingo Mobile App

An Android Analog Clock application built with Kotlin & Jetpack Compose (60 FPS Canvas Dial, Sweeping vs. Mechanical Ticking, Escapement Audio) and a luxury Bakingo Mobile Application.

## 🚀 Automated APK Build
This repository includes a GitHub Actions workflow in [`.github/workflows/build-apk.yml`](.github/workflows/build-apk.yml). On every push, GitHub automatically compiles the Android APK and makes it available for download under the **Actions** tab.
